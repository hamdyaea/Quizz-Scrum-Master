# Scrum Master Quiz

**Developer:** Hamdy Abou El Anein  
**Contact:** info@daylightlinux.ch  
**License:** GPL v3 (see LICENSE).

A modern Python 3/Tkinter quiz preserving the original five Scrum questions. It features navigable multiple-choice questions, answer tracking, a score summary and restart. The question wording reflects historical training material and should not be treated as an authoritative statement of the latest Scrum Guide.

```sh
python3 quizz-OK.py
python3 -m unittest discover -s tests -v
```

No external Python dependencies. Original code is preserved on [old](https://github.com/hamdyaea/Quizz-Scrum-Master/tree/old).
